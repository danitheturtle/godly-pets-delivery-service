* Only state-based puzzles. Nothing requiring precision input skill or timing
* Complexity through the dynamics that emerge from atomic game objects
* Don't fight the game engine
* Immediate, clear feedback for every action

Other design considerations
* Puzzles should be solvable in black and white (colorblind friendly)

Artstyle
* Flat, vibrant colors
* No gradients except weathering; cell shaded transitions for core texture
* Accentuate edges with lighter / darker colors
* Minimal normal maps
